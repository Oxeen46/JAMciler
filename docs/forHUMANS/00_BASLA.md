# 🧭 Buradan başla

> **Bu belge:** Ekibe ilk katıldığında hangi sırayla ilerleyeceğini açıklar.

## 1. Rol seçimi

1. [Dört paketi](02_GOREV_PAKETLERI.md) oku.
2. Ekipçe birer paket seçin; adlar henüz atanmış değildir.
3. Seçimleri [sahiplik tablosunda](03_DOSYA_SAHIPLIGI.md) kesinleştirin.

## 2. Kurulum

1. [Ortak kurulum](01_ORTAK_KURULUM.md) adımlarını izle.
2. Kendi isimli branch'ini seç.
3. Oyun projesi geldiğinde açılış/derleme testini tamamla.

## 3. Her gün

1. [Günlük akış](04_GUNLUK_GITHUB.md) ile güncellemeleri al.
2. Sana ait görev kartında çalış, test et.
3. [PR ile teslim et](05_PR_VE_MAIN.md).

| Terim | Anlam |
|---|---|
| Repo | Dosyalar ve değişiklik geçmişi |
| Clone | Repoyu ilk kez bilgisayara alma |
| Branch | Bütün projenin ayrı çalışma çizgisi; yalnız kişisel klasör değildir |
| Commit | Bilgisayarda açıklamalı değişiklik kaydı |
| Push | Kayıtları GitHub'a gönderme |
| Fetch | GitHub'daki yeni kayıtları öğrenme |
| Pull | Bulunduğun branch'in uzak güncellemelerini alma |
| Merge | İki çalışma çizgisini birleştirme |
| PR | Ortak sürüme alınması için inceleme isteği |
| LFS | Büyük dosyaların içeriğini ayrı depolamada tutan sistem |

> [!TIP]
> 🟢 Adım · 🔵 Açıklama · 🟡 Kontrol. Renklerin yanında her zaman açıklayıcı metin bulunur.
