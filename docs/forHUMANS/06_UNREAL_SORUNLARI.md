# 🩺 Unreal açılış sorunları

> **Bu belge:** Uyarıları ayırır. Tam mesaj görülmeden dönüşüm veya dosya silme önermez.

| Durum | İlk kontrol |
|---|---|
| Open a Copy / Convert in Place | Motor tam sürüm/dağıtımı ve EngineAssociation |
| Missing modules / Rebuild now | C++ araçları/SDK ve yerel derleme |
| Varlık yerine küçük metin | LFS indirilmiş mi, kota dolmuş mu? |
| Eksik plugin | Doğru sürüm, lisans ve kurulum |

1. Mesajın tam ekran görüntüsünü ve motor sürümünü al; kişisel bilgileri public Issue'ya koyma.
2. [Ortak kurulum](01_ORTAK_KURULUM.md) ile karşılaştır.
3. Doğru repo kopyasını açtığını doğrula; rastgele dönüştürülmüş kopyada çalışmaya devam etme.
4. Yeni motorla kaydedilmiş projeyi eski motorla açmaya çalışma.
5. Modül sorunu için derleme çıktısındaki ilk gerçek hatayı paylaş; her hata dönüşümle çözülmez.

Kaynak: https://dev.epicgames.com/documentation/en-us/unreal-engine/opening-an-existing-unreal-engine-project
